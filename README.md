# HomeLeson 14.1

В проекте реализованы классы `Product` и `Category`.

Класс `Product` содержит название, описание, цену и количество товара.

Класс `Category` содержит название, описание и список товаров.

Для класса `Category` реализован автоматический подсчёт количества категорий и общего количества товаров.

Также для основных классов написаны тесты с использованием `pytest`.
