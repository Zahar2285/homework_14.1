## Домашняя работа 16.1 — Наследование классов

В проект добавлены классы-наследники `Smartphone` и `LawnGrass`, расширяющие базовый класс `Product`.

### Реализованная функциональность

- `Smartphone` содержит атрибуты `efficiency`, `model`, `memory` и `color`.
- `LawnGrass` содержит атрибуты `country`, `germination_period` и `color`.
- Реализовано ограничение сложения: складывать можно только товары одного класса. При попытке сложить товары разных классов возникает `TypeError`.
- Метод `Category.add_product()` проверяет, что добавляемый объект является экземпляром `Product` или его наследника.
- Добавлены тесты для наследования, сложения товаров и проверки добавления объектов в категорию.

### Проверка проекта

Запуск тестов:

```bash
poetry run pytest
```

Проверка стиля кода:

```bash
poetry run flake8 .
```

Создание HTML-отчёта покрытия:

```bash
poetry run pytest --cov=src --cov-report=html
```

На момент выполнения домашней работы все 16 тестов проходят, покрытие функционального кода составляет 100%, ошибок `flake8` нет.
